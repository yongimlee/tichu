# Tichu (웹)

4인 2팀 트릭테이킹 카드게임 **Tichu**를 웹에서 플레이하기 위한 프로젝트입니다.
TypeScript 풀스택 모노레포로 구성되어 있으며, 추후 모바일(Capacitor 등) 확장을
염두에 두고 **게임 로직과 화면 코드를 분리**해 두었습니다.

## 구조

```
tichu/
├─ shared/   # 순수 TypeScript 도메인 (카드, 족보, 방/이벤트 타입). 화면 의존성 없음 → 모든 클라이언트가 재사용
├─ server/   # Express + Socket.IO 게임 서버 (상태의 단일 출처, server-authoritative)
└─ web/      # React + Vite 웹 클라이언트
```

- `shared`는 브라우저/DOM에 의존하지 않으므로, 나중에 모바일 클라이언트를 추가할 때
  카드·족보·게임 규칙·소켓 이벤트 타입을 **그대로 가져다 쓸 수 있습니다.**
- 서버는 플랫폼과 무관하므로 웹/모바일이 동일한 서버에 접속합니다.

## 시작하기

```bash
npm install          # 워크스페이스 전체 의존성 설치
npm run dev          # 서버(:3001) + 웹(:5173) 동시 실행
```

개별 실행:

```bash
npm run dev:server   # 게임 서버만
npm run dev:web      # 웹 클라이언트만
npm run typecheck    # 전체 타입 체크
```

웹: http://localhost:5173 · 서버 헬스체크: http://localhost:3001/health

## 방 모집 흐름

1. **호스트**가 닉네임을 입력하고 팀 선정 방식(직접 선택 / 랜덤 배정)을 골라 방을 만듭니다.
2. 생성된 **초대 코드**(예: `ABC123`)를 게스트에게 전달합니다.
3. **게스트**는 닉네임과 초대 코드를 입력해 입장합니다. (최대 4인)
4. 팀 구성
   - **직접 선택**: 각자 원하는 자리(팀 A: 0·2번, 팀 B: 1·3번)에 앉습니다.
   - **랜덤 배정**: 방장이 "팀 랜덤 배정"으로 4명의 자리를 무작위 배정합니다.
5. 4명이 모두 앉으면 방장이 게임을 시작합니다.

> Tichu에서는 파트너가 마주보고 앉습니다 — 자리 0·2가 한 팀, 1·3이 다른 팀입니다.

## 온라인 배포 (단일 서비스)

서버가 빌드된 웹(`web/dist`)까지 **같은 출처(origin)** 에서 서빙하므로, 서비스 하나만 띄우면 됩니다
(CORS 불필요, URL 하나). 프로덕션 동작 방식:

- `npm run build` → 웹을 `web/dist`로 빌드
- `npm start` → 서버가 Socket.IO + 정적 웹(dist)을 함께 서빙 (`web/dist`가 있으면 자동 감지)
- 포트는 `process.env.PORT`(호스트가 자동 주입), 미설정 시 3001

로컬에서 프로덕션 모드 확인:

```bash
npm run build
npm start            # http://localhost:3001 에서 웹 + 게임 서버
```

### Render 배포 (블루프린트 포함)

1. 이 저장소를 GitHub에 push.
2. [render.com](https://render.com) → **New → Blueprint** → 저장소 선택 (루트의 `render.yaml` 사용).
   - Build: `npm install --include=dev && npm run build`
   - Start: `npm start`
   - Health check: `/health`
3. 배포 완료 후 받은 URL을 친구에게 공유 → 방 만들기/초대 코드로 플레이.

> 환경변수: 단일 배포에서는 별도 설정이 필요 없습니다. (웹↔서버를 분리 배포할 때만
> 서버에 `CLIENT_ORIGIN`, 웹 빌드에 `VITE_SERVER_URL`을 지정하세요.)

**한계**: 게임 상태가 메모리에 있어 **인스턴스 1개**만 가능하고, 재배포/재시작 시 진행 중
게임이 사라집니다. 무료 티어(Render 등)는 미사용 시 슬립하여 첫 접속이 느릴 수 있습니다.

## 테스트

게임 로직(족보·분배·교환·트릭·점수)은 `shared`에 순수 함수로 있고 단위 테스트가 있습니다.

```bash
npm test -w @tichu/shared   # node:test 러너로 31개 테스트 실행
```

## 구현 상태

✅ 모노레포 / 빌드 구성, 공유 도메인 타입, Socket.IO 서버·클라이언트 연결
✅ 방 생성 / 초대 코드 입장 / 닉네임 / 팀 선정(직접·랜덤) / 로비
✅ 족보 판정·비교 (`shared/src/combinations.ts`) — 싱글·페어·트리플·풀하우스·스트레이트·계단·폭탄·봉황 와일드카드
✅ 카드 분배(8장 → 라지 티츄 → 6장) 및 3장 교환
✅ 트릭 진행(리드·팔로우·패스·트릭 종료), 폭탄(차례 외 끼어들기 포함), 특수 카드(참새 소원·개·봉황·용)
✅ 참새 "소원" 강제 이행 — 소원 랭크를 포함한 합법 수를 낼 수 있으면 반드시 이행(비이행 수·패스 차단)
✅ 점수 계산(카드 점수·티츄/라지티츄 보너스·원투 피니시·잔여 카드 분배), 1000점 매치 상태 머신
